# Khadavli Digital Hub – Logo Package

The original file was a 3D signboard mockup (JPEG). This folder contains a clean
vector rebuild of that logo, ready to use anywhere.

## What to use where

| Need | File |
|---|---|
| Print, large banners, designers, editable master | `svg/kdh-logo-stacked-light.svg` (light backgrounds) / `svg/kdh-logo-stacked-dark.svg` (dark backgrounds) |
| Website header / letterhead (wide) | `svg/kdh-logo-horizontal-light.svg` or `png/kdh-logo-horizontal-light-1200w.png` |
| Transparent PNG for posts, WhatsApp, documents | `png/kdh-logo-stacked-light-2400w.png` (also 1200w, 600w) |
| Flat JPG (no transparency) | `png/kdh-logo-stacked-on-white-2400w.jpg`, `png/kdh-logo-stacked-on-black-2400w.jpg` |
| Symbol only (K mark) | `svg/kdh-mark-light.svg`, `png/kdh-mark-light-*.png` (2048 to 128 px) |
| Profile picture / app icon (square) | `png/kdh-icon-square-white-1024.png`, `png/kdh-icon-square-dark-1024.png` |
| Website favicon | `favicon.ico`, `png/kdh-icon-32.png`, `png/kdh-icon-180.png` (Apple), `png/kdh-icon-192.png`, `png/kdh-icon-512.png` |
| Original 3D signboard look, background removed | `photo-cutout/kdh-logo-3d-from-photo.png` (raster, has slight glow edges; use only when the 3D look is wanted) |

`kdh-logo-preview.png` shows every variant on one sheet.

"light" = version for light backgrounds (black text). "dark" = version for dark backgrounds (white text).

## Brand colours

| Element | Hex |
|---|---|
| Black (text, K) | `#121212` |
| Saffron band | `#FF8A1E` |
| White band | `#FFFFFF` (`#F1EFEA` in the light version so it stays visible on white) |
| Green band | `#15871C` |
| Gold (pixels, HUB) | `#F8C650` to `#C8880E` gradient; K edge `#D9A235` |

## Fonts

Montserrat Black (wordmark) and Montserrat SemiBold (tagline). All text in the
SVGs is converted to outlines, so no font installation is needed anywhere.
